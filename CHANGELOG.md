## [0.0.1] - 2025-11-17

### Added
- Initial project setup with Vite and React 18
- VietlottForm component with date and lottery type selection
- Support for two lottery types:
  - Mega 6/55
  - Power 6/45
- Form validation for required date field
- Reset functionality to clear form inputs
- Basic CSS styling for form components
- Radio button selection for lottery types
- Form submission handler (console logging)
- Alert notification for form submission

### Project Structure
- Created component-based architecture
- Separated component styles into dedicated CSS files
- Set up development environment with Vite
- Configured React with StrictMode

### Developer Experience
- Hot Module Replacement (HMR) enabled
- Development server with fast refresh
- Production build optimization
- Preview mode for testing production builds
